## Status Lifecycle

Use one of these status values exactly:

| Status | Meaning |
| --- | --- |
| `Proposed` | The decision is under consideration and is not current project guidance. |
| `Accepted` | The decision is current project guidance. |
| `Superseded` | The decision has been replaced by a later ADR. |
| `Deprecated` | The decision is no longer recommended, with or without a direct replacement. |

Allowed transitions:

- `Proposed` to `Accepted`
- `Accepted` to `Superseded`
- `Accepted` to `Deprecated`
- `Superseded` to `Deprecated`

Preserve historical records when a decision changes. Update the status and related records instead of deleting or renumbering existing ADRs.
